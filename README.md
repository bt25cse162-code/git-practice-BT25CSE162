## Assignment Description

This repository contains the C++ exercises and Git command documentation completed as part of the Git Practice Assignment.

## Exercises

### Exercise 1: Order Tracking System
- File: `exercise-01/main.cpp`
- Description: Uses a static data member to count the number of order objects created and displays the order IDs and total order count.

### Exercise 2: Bank Interest System
- File: `exercise-02/main.cpp`
- Description: Uses a static interest rate shared by bank accounts and a static member function to update the rate.

## How to Compile and Run

Use a C++ compiler such as g++.

### Exercise 1

```bash
g++ exercise-01/main.cpp -o exercise1
./exercise1
```

### Exercise 2

```bash
g++ exercise-02/main.cpp -o exercise2
./exercise2
```

On Windows, run the compiled programs using `exercise1.exe` and `exercise2.exe`, respectively.
